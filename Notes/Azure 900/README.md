## Learning Path

1. Start with cloud concepts and why Azure exists.
2. Understand Azure's global infrastructure and regions.
3. Learn about compute services and when to use each one.
4. Master networking, load balancing, and content delivery.

## Key Exam Focus Areas

- Cloud deployment models (Public, Private, Hybrid)
- Azure regions, availability zones, and data residency
- IaaS vs. PaaS vs. SaaS service models
- Virtual Machines, App Service, Functions, and Containers
- Virtual Networks, Load Balancers, and CDN
