# AZ 204

Tags: azure, cloud, certification

This folder contains Azure Developer Associate (AZ-204) certification notes covering core Azure services including compute, data, messaging, and deployment patterns. These notes focus on practical implementation using the Azure SDK and REST APIs.

## Learning Path

1. Start with Virtual Machines and compute fundamentals.
2. Learn relational database options: SQL Database, Elastic Pools, Managed Instance.
3. Understand NoSQL with Cosmos DB.
4. Master App Service for web application hosting.
5. Integrate services with messaging, caching, and deployment patterns.

## Key Exam Areas

- Azure compute services (VMs, App Service, Functions)
- Data storage (SQL Database, Cosmos DB, Storage)
- Authentication and authorization
- Networking and security
- Deployment and CI/CD
- Azure SDK usage with C#
- REST API integration
